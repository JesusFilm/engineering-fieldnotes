## Content verdict: keep as core

A team beginning agentic engineering needs reproducible setup, actionable failures, current evidence and inspectable handoffs immediately. This guide turns that need into a small local exercise instead of requiring a new platform. Tool design and context engineering are useful prerequisites; session continuity and feature lists can be learned as complementary mechanisms after the acceptance loop.

The exercise previously proved that tests fail and later pass, but did not explicitly exercise the stated outcome that a failure prevents advancement. Added a runner-owned ready-for-review marker, deliberately withheld on failure while retaining failure output; its success criterion is observable. This is a local control, not a repository permission claim. The team still owns test adequacy, changes to the tests, permissions and release decisions. Retrieval dates were added to all four guide source records.
