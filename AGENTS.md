# Engineering Fieldnotes

A reading library for experienced engineers adopting AI-assisted and agentic workflows. Preserve the quiet index layout, concrete examples, and explicit limits of each technique.

For content or video changes, read `docs/editorial-workflow.md`. For page layout and interaction changes, read `docs/design.md`. Track unfinished launch requirements in `docs/launch.md`.

Author concepts in `content/concepts/`, media in `public/media/<concept>/`, and reproducible scenes in `video/<concept>/<variant>/`. The build generates `dist/`; edit source instead. Keep each parallel worker inside its assigned concept and variant. The coordinator owns shared manifests, build scripts, and Git operations.

Keep review scores separate from factual verification. Model identity describes provenance, not quality. A recommended video needs a comparative review against the alternatives.
